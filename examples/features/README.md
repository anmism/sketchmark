# Feature Examples

These examples are canonical primitive JSON documents. They are meant to be copied by agents as stable patterns.

1. `01-primitives.visual.json` - all core 2D primitives.
2. `02-coordinate-model.visual.json` - top-left boxes, center circles, endpoint lines.
3. `03-reference-anchors.visual.json` - reference endpoints such as `box.right`.
4. `04-groups.visual.json` - grouped local children.
5. `05-animation-basics.visual.json` - explicit primitive property animation.
6. `06-keyframes.visual.json` - keyframe animation.
7. `07-follow-arrow-packet.visual.json` - packet following an arrow.
8. `08-follow-path-orbit.visual.json` - packet following a curved path.
9. `09-patch-targets.visual.json` - stable ids for AI patch operations.
10. `10-dashboard-tiles.visual.json` - dashboard layout with primitives.
11. `11-education-fractions.visual.json` - educational visual explanation.
12. `12-water-cycle.visual.json` - explainer diagram.
13. `13-system-architecture.visual.json` - architecture flow.
14. `14-data-story-bars.visual.json` - chart-like primitives.
15. `15-callout-annotation.visual.json` - callout built from primitives.
16. `16-image-data-uri.visual.json` - image primitive.
17. `17-scenes-sequence.visual.json` - scenes and a sequence.
18. `18-deck-build-steps.visual.json` - deck build steps.
19. `19-structured-three-chart.visual.json` - structured 3D chart.
20. `20-structured-three-product.visual.json` - structured 3D product diagram.
21. `21-mixed-2d-3d-sequence.visual.json` - mixed 2D and 3D sequence.
22. `22-mixed-2d-3d-10s-animation.visual.json` - 10-second mixed 2D animation and 3D shots.
